이용 안내

RIDE DNA는 나의 라이딩 선호와 어울리는 모터사이클 스타일을 재미있게 탐색하도록 만든 무료 비공식 테스트입니다. 공식 심리검사, 구매 적합도 또는 안전성 평가가 아닙니다.

테스트는 어떻게 계산하나요?

빠른 검사는 공통 16문항, 심화 검사는 공통 16문항에 5단계 동의 방식의 추가 24문항을 더합니다. 경험이 필요한 일부 질문은 경험 없음으로 응답할 수 있으며, 이 답변은 중립과 구분해 계산에서 제외합니다. 심화 검사에서는 선호가 가까운 두 장르를 구분하기 위해 최대 8문항을 추가할 수 있습니다. 공통 객관식과 심화 선호 응답을 바탕으로 8개의 취향 지표를 산출하고 바이크 장르별 설정값과 비교합니다. 심화 검사의 새 점수 계산은 실제 라이더 표본으로 검증되지 않은 실험 모델입니다. 빠른 검사 후 기존 응답을 유지한 채 심화 검사를 이어서 진행할 수 있습니다. 16가지 라이더 유형은 결과를 설명하기 위한 자체 창작 분류입니다.

왜 별도의 성격 검사가 없나요?

RIDE DNA는 바이크와 라이딩에 대한 취향을 탐색하는 게임이에요. 이전에 제공하던 비공식 예상 MBTI 기능은 추정의 한계와 서비스 목적을 고려해 v1.9.0부터 제공하지 않습니다. 기존 저장 데이터의 성격 정보는 더 이상 화면에 표시하거나 새 공유 링크에 추가하지 않습니다. 이전에 만든 공유 링크의 기본 라이더 유형 결과는 계속 확인할 수 있어요.

개인정보와 응답 저장

회원가입 없이 이용할 수 있으며 응답을 RIDE DNA의 서버로 전송하지 않습니다. 진행 상태와 본인의 결과는 이용자 기기의 브라우저 로컬 저장 공간(localStorage)에 저장되므로 같은 브라우저에서 다시 접속해 이어서 진행할 수 있습니다. 저장한 정보를 지우려면 브라우저의 해당 사이트 데이터 삭제 기능을 이용하세요. 공용 기기에서는 테스트 후 사이트 데이터를 삭제하는 것을 권장합니다.

공유 링크에는 라이더 유형 번호, 추천 바이크 장르 두 가지, 검사 종류가 포함됩니다. 기존 URL에 포함돼 있던 MBTI 매개변수는 v1.9.0에서 무시합니다. 개별 답변은 포함되지 않습니다. 공유 링크를 받은 사람은 요약 결과만 볼 수 있습니다.

친구 비교와 데이터 보안

RIDER DUO는 URL에 담긴 두 사람의 요약 결과를 브라우저에서 직접 비교합니다. 친구 초대 요약은 같은 브라우저 탭의 세션 저장소에 잠시 보관할 수 있습니다. 별도의 서버로 전송하지 않으며, 실제 주행 적합성이나 인간관계 궁합을 판정하는 것이 아닙니다. 공유받은 링크는 수정될 수 있으므로 결과의 진위를 인증하지 않습니다.

화면 연출과 접근성

화면 상단의 연출 설정에서 기본, 화려하게, 움직임 끄기 중 선택할 수 있습니다. 첫 방문에는 기기에서 동작 줄이기 설정을 켰다면 움직임을 끈 상태로 시작합니다. 검사 완료 연출은 건너뛸 수 있으며, 연출을 끄더라도 검사 결과와 점수는 달라지지 않습니다. DNA SIGNATURE는 라이딩 취향의 8가지 지표를 시각화한 그림입니다. 16개 유형의 엠블럼, 추천 장르별 그래픽과 라이더 카드의 3가지 디자인은 장식적 표현으로, 검사 채점에 영향을 주지 않습니다. 라이더 카드 앞면과 뒷면은 브라우저에서 직접 PNG로 저장할 수 있어요. 유형 도감에서 다른 엠블럼을 둘러봐도 본인의 검사 결과는 바뀌지 않습니다. 공유된 요약 링크에서는 세부 점수 없이 장르 정보를 기반으로 그림을 보여주므로 본인이 저장한 카드와 동일한 정밀 데이터를 나타내지 않을 수 있습니다.

사이트 자산과 기술

사이트는 GitHub Pages에서 실행할 수 있는 정적 HTML·CSS·JavaScript로 구성되어 있습니다. 메인 화면에는 사진이 없고, 공유 이미지·사이트 아이콘은 로컬 파일입니다. 별도 추적기와 웹폰트 CDN을 사용하지 않습니다. 카카오톡 직접 공유를 설정한 경우에만 카카오 JavaScript SDK를 추가로 불러옵니다.

참고 바이크 기종

예시 기종은 장르를 이해하기 위한 참고 자료입니다. 판매 여부와 가격, 운전면허, 차량 제원과 실제 체격에 따른 적합성, 보험 및 유지비 등은 별도로 확인해야 합니다.
